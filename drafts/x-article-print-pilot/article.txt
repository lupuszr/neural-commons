I want to introduce Neural Commons: a place where AI agents can change a model’s weights, test what happened, and pass the model and its evidence to the next participant through OriginTrail DKG.

Here is the latest experiment. An agent tried to improve a model that recognizes defects in real 3D-print photographs. Its chosen change looked better during selection. Then it failed the final test.

We kept the previous model.

Start with something concrete.

200 real photographs. Four defect categories: cracking, shifted layers, stringing and warping. The task was to distinguish those defects, not to decide whether a print was healthy.

100 images were used to develop changes. 40 were used to select a candidate. 60 previously unused images were reserved for the final comparison.

The discovery agent was the Codex assistant working with me. It inspected errors, proposed numerical changes inside CLIP’s visual network, ran them with Python, read the results and decided what to try next. Python was its tool. The assistant chose the experiments.

Seven attempts. Feedback changed the direction.

First, it tried amplifying channels associated with cracks. No improvement. A stronger correction recovered some cracks but damaged recognition of shifted layers. Attempts to protect that class also failed.

It then changed direction: correct the remaining development errors together. That reached perfect development accuracy and made selection worse. Reducing the edit’s strength finally moved selection from 29/40 to 30/40.

That candidate was frozen before the final test.

What actually changed?

2,359,275 values in one internal weight tensor: the MLP output projection in block 9. The classifier head stayed fixed. So did 397 other tensors. These were direct numerical edits, without gradients or an optimizer.

A separate verification process replayed the additive patch and recovered the exact candidate weights.

Now test the claim.

On the same 60 final images:

Inherited model: 29 correct.
Edited candidate: 27 correct.

Zero errors corrected. Two new errors introduced.

The candidate was rejected. We retained the inherited checkpoint and recorded the failed branch. We did not tune another candidate against those final results.

Why keep a failed experiment?

Because the next agent needs to know what was tried, what changed and what broke. A higher selection score is a reason to test a candidate. It is not a reason to accept it.

Neural Commons preserves the checkpoint identity, exact patch, evaluation and decision. OriginTrail’s DKG provides the shared context graph for participants to discover that evidence and continue the work. An earlier, separate demonstration verified a two-node handoff on one Mac. This real-photo experiment was local; it was not yet transferred through DKG.

The limits matter.

The photographs come from Hu et al.’s public FDM defect dataset, using its source labels. The final frames were new to these experiments, but came from capture sessions already represented in earlier evaluations. This is exploratory evidence, not proof of generalization to independent print jobs or a production failure detector.

That is the next test: independent jobs, reviewed labels, and another agent starting from the retained model with the full record.
